# RSCM Slot Monitor

An automated Python application that monitors RSCM doctor appointment availability through API integration and sends real-time Telegram notifications when appointment slots become available.

## Features

- Monitor doctor schedules
- Detect newly available appointment slots
- Telegram notifications
- Automatic periodic execution
- REST API integration

## Tech Stack

- Python
- Requests
- Telegram Bot API
- Windows Task Scheduler

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
